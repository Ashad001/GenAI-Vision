-------------vgg16---------------------------
his script performs multi-class image classification using transfer learning with VGG16.
It first splits the dataset into training (70%), validation (15%), and test (15%) sets by moving images into corresponding class-based directories. 
Images are then loaded using Keras' ImageDataGenerator, applying rescaling to normalize pixel values.
The model uses a pre-trained VGG16 base with frozen weights, followed by global average pooling and two dense layers, ending with a softmax layer for classifying 20 categories.
It is compiled with the Adam optimizer and categorical crossentropy loss, suitable for multi-class classification with one-hot encoded labels. 
The model is initially evaluated on the test set and then trained for 15 epochs using the training and validation datasets.

accuracy: 0.6505 - loss: 1.1593
