# **GenAI Vision** 🏙️🧠  

## **Overview**  
GenAI Vision is a **multi-label image classification project** focused on the **PASCAL VOC 2008 dataset**, exploring the impact of **synthetic data augmentation** on classification performance. We apply **transfer learning with modern CNN architectures** and analyze how synthetic samples generated by **Variational AutoEncoders (VAEs) and Deep Convolutional Generative Adversarial Networks (DCGANs)** affect classification accuracy. The project evaluates all approaches using **Mean Average Precision (mAP)** as the primary metric.

---

## **Features**  
✅ **Transfer Learning with Three Modern Architectures** – VGG16_BN, ResNet50, and EfficientNet_B3  
✅ **Synthetic Data Generation** – Using **VAE** and **DCGAN**  
✅ **Performance Evaluation** – Measuring impact of augmentation on mAP  
✅ **Comparative Analysis** – Contrasting different augmentation strategies

## **Dataset**  
- **Source:** [PASCAL VOC 2008](http://host.robots.ox.ac.uk/pascal/VOC/voc2008/index.html)  
- **Split Used:** `train` → Training, `val` → Evaluation  

---

## **Methodology**  

### **1. Transfer Learning with Modern Architectures**  
- Implemented **VGG16_BN, ResNet50, and EfficientNet_B3** pre-trained on **ImageNet**  
- Fine-tuned for PASCAL VOC 2008 multi-label classification  
- Evaluated using **Mean Average Precision (mAP)**, **F1 Score**, and **Accuracy**  
- Generated visualizations of **Top 10 ranked classified images** per class

### **2. Variational AutoEncoder (VAE) Augmentation**  
- Trained **VAE** models to generate synthetic images for each class  
- Augmented dataset with **100, 200, and 500 samples per class**  
- Retrained classifiers and analyzed performance changes  
- Found modest but consistent improvements, especially with 200 samples per class

### **3. Deep Convolutional GAN (DCGAN) Augmentation**  
- Trained separate **DCGAN** models for each of the 20 PASCAL VOC classes
- Generated synthetic images at 64×64 resolution with class-specific generators
- Augmented training data with **100, 200, and 500 samples per class**
- Implemented label smoothing, instance noise, and dropout for GAN stability
- Observed performance degradation as synthetic sample count increased

### **4. Comparative Analysis & Discussion**  
- **Performance metrics:** Comprehensive comparison of baseline vs. augmented performance
- **Visualization:** Class-specific top-ranked images and mAP vs. augmentation curves
- **Analysis:** Contrasting effects of VAE (positive) vs. DCGAN (negative) augmentation
- **Findings:** Identified critical factors affecting synthetic data effectiveness including sample quality, distribution alignment, and multi-label context

## **Results & Findings**  
📌 **EfficientNet_B3 achieved the best baseline performance (mAP: 70.82%)**  
📌 **VAE augmentation provided modest but consistent performance improvements**  
📌 **DCGAN augmentation unexpectedly degraded performance, with worse results as synthetic sample count increased**  
📌 **Synthetic data quality and distribution alignment are critical factors for successful augmentation**
